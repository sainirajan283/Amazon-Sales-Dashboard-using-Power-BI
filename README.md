# 📊 Amazon Sales Dashboard (Power BI)

This repository contains a Power BI dashboard that visualizes Amazon sales data.  
It helps track performance, identify trends, and analyze KPIs for better decision-making.

## 🔑 Features
- Interactive charts for revenue, orders, and product categories
- Filters by date range, region, and product type
- KPIs such as total sales, average order value, and top-selling products

## 📂 File
- `AmazonSalesDashboard.pbix` → Power BI file

## 🚀 Usage
1. Download the `.pbix` file.
2. Open it in **Power BI Desktop**.
3. Connect to your dataset (CSV, Excel, SQL, or API).
4. Explore and customize the dashboard.
